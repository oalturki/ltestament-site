# موسوعة التفسير الموضوعي — مصدر تبويب «المواضيع»

- **المصدر:** موسوعة التفسير الموضوعي – مركز تفسير للدراسات القرآنية (https://modoee.com)، كما تعرضها منصة سورة (https://web.surahapp.com/ar/objective-interpretation).
- **الإذن:** من مدير المركز (نوفمبر 2026)، بشرط ألّا يُعدَّل نصّ الموسوعة (لا تلخيص ولا إعادة صياغة ولا ترجمة)، وأن يُنقل المقتبس بنصّه، ويُنسب بوضوح إلى «موسوعة التفسير الموضوعي – مركز تفسير للدراسات القرآنية».
- **ما نأخذه:** أسماء الأقسام والمواضيع والعناصر بنصّها، والإحالات القرآنية تحت كل عنصر. لا نأخذ نصّ الشرح.

## الاستخراج (26 نوفمبر 2026)
`raw.json.gz` استُخرج في متصفح على web.surahapp.com من واجهة المنصة:
`https://generator.surahapp.com/modoee/api/v1/?section=<id>` و `?topic=<id>` (حقل `txt` هو HTML الموضوع).
العناصر: `p.main-title`، والعناصر الفرعية: `p.colored-side-title`، والإحالات: كل ما بين `[…]` وفيه «:» ورقم.
18 قسمًا، 333 موضوعًا.

## البناء
`python3 tools/build_topics.py` → `data/topics/modoee.json`
